# Select & Highlight

Minimal Chrome extension that creates a shareable link using Text Fragments (`#:~:text=`).

## Load in Chrome
1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked** and choose this folder.

## Usage
1. Select text on any page.
2. Right‑click → **Select & Highlight**.
3. Paste the copied link anywhere.

## Notes
- If the selected text appears multiple times, the highlight may land on a different match.
- Dynamic pages can break the match if content changes after load.
